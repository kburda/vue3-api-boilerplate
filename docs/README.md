# Vue 3 API Boilerplate (Secure Edition)

## ✅ Features
- Vue 3 + Vite + TS
- Pinia store
- Axios client with interceptors
- API factory pattern
- Service contracts
- Authentication composable
- Secure API call strategies

## 🔒 Security
- `.env` for API URLs and storage config
- `.gitignore` prevents leaking `.env`
- Axios timeout + CSRF cookie support
- Automatic token refresh
- Forced re-auth on refresh failure
- Logout request to backend
